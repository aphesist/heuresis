# Research behind v2

`validated-agentic-retrieval-and-safe-evolution.md` is the report (November 2026). It
answers one question: how can an engine over large, time-versioned corpora reach
agentic-level accuracy while giving only validated answers or typed abstentions, and how
can a Darwin-Gödel-Machine-style improvement loop run over it without gaming its
benchmarks. Its sections are numbered so `docs/design-v2.md` can cite them (R§1.3 and so on).

Every claim in it is labelled: **[M]** measured by the cited authors, **[V]** vendor-claimed,
**[S]** secondary or unverified (search summary, abstract, aggregator), **[I]** inference.
Nothing in it was measured by this project. Section 10 lists what could not be verified.

`notes/` holds the nine source notes the report was written from, with links per claim.
